# Screenshot checklist

This directory is reserved for sanitized release screenshots:

The current `shift-plus-icon.png` is the real Android product icon. The remaining
release screenshots are intentionally pending:

- `android-monthly-roster.png`
- `android-today-duty.png`
- `home-assistant-dashboard.png`
- `home-assistant-roster-card.png`
- `pairing.png`

Do not add images containing names, private entity IDs, URLs, addresses, tokens,
QR codes or other personal/security-sensitive data. Existing development images
were not copied because they use older branding, incomplete setup data, or do not
show the Home Assistant companion experience. Capture final images only after
the real end-to-end test environment is ready.
